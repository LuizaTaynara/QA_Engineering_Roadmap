# 2.07. Test Strategy
A **Estratégia de Testes** define a abordagem que será utilizada para planejar, projetar, executar e gerenciar as atividades de teste ao longo do projeto.

Seu objetivo é orientar como os testes serão conduzidos para garantir que o software atenda aos requisitos e aos padrões de qualidade estabelecidos.

A estratégia de testes busca definir a abordagem mais adequada para validar a qualidade do software, considerando fatores como riscos, escopo, recursos disponíveis e objetivos do projeto.

Ela serve como um guia para orientar as decisões relacionadas aos testes durante todo o ciclo de desenvolvimento.

## O que uma estratégia de testes pode definir?
Uma estratégia de testes pode incluir informações como:
- Objetivos dos testes.
- Níveis e tipos de testes que serão realizados.
- Critérios para priorização dos testes.
- Abordagem baseada em riscos.
- Ferramentas e ambientes de teste.
- Nível de automação esperado.
- Critérios para avaliação dos resultados.

O nível de detalhamento pode variar conforme a organização e a metodologia utilizada.

## Test Strategy × Test Plan
Embora estejam relacionados, esses documentos possuem objetivos diferentes.

| Test Strategy                                                              | Test Plan                                                    |
| -------------------------------------------------------------------------- | ------------------------------------------------------------ |
| Define **como** os testes serão conduzidos.                                | Define **como o trabalho será organizado**.                  |
| Possui uma visão mais ampla e pode ser reutilizada em diferentes projetos. | É específico para um projeto ou uma entrega.                 |
| Estabelece a abordagem geral dos testes.                                   | Define cronograma, recursos, responsabilidades e atividades. |

## O papel do QA
O QA contribui para a definição da estratégia de testes, considerando os requisitos, os riscos do projeto e as características da aplicação. Essa estratégia orienta a escolha das abordagens de teste mais adequadas e auxilia na definição das prioridades durante a execução.

## 💡 Boa prática
A estratégia de testes deve ser compatível com o contexto do projeto. Aplicações críticas podem exigir uma abordagem mais rigorosa, enquanto projetos menores ou com mudanças frequentes podem adotar estratégias mais flexíveis.
