# 2.09. Test Scenarios
Os **Cenários de Teste** descrevem, de forma geral, as funcionalidades, fluxos ou situações que devem ser testadas para verificar se os requisitos foram atendidos.

Eles representam **o que deve ser validado**, sem detalhar os passos necessários para executar o teste.

Os cenários de teste têm como objetivo identificar e organizar as principais situações que precisam ser validadas, garantindo que os requisitos e critérios de aceite sejam cobertos pelos testes.

Eles servem como base para a criação dos casos de teste.

Um bom cenário de teste deve ser:
- Claro e objetivo.
- Alinhado aos requisitos e critérios de aceite.
- Focado em uma funcionalidade ou comportamento específico.
- Independente de detalhes de execução.

## Exemplo:
### Funcionalidade: 
Login de usuário.

### Test Scenarios:
- Validar login com credenciais válidas.
- Validar login com senha incorreta.
- Validar login com usuário inexistente.
- Validar campos obrigatórios.
- Validar recuperação de senha.

Um cenário de teste deve descrever apenas o comportamento que será validado. Os detalhes da execução, como passos, dados de teste e resultados esperados, pertencem aos casos de teste.

## Test Scenario × Test Case
Embora estejam relacionados, possuem objetivos diferentes.

| Test Scenario                           | Test Case                                                        |
| --------------------------------------- | ---------------------------------------------------------------- |
| Define **o que será testado**.          | Define **como o teste será executado**.                          |
| Possui uma visão mais ampla.            | Contém passos detalhados, dados de teste e resultados esperados. |
| Serve como base para os casos de teste. | Permite executar e validar o comportamento da funcionalidade.    |


> Na prática, um cenário de teste representa um **objetivo de validação**. Ele responde à pergunta: <br> **"Qual comportamento do sistema precisa ser verificado?"** <br>
Já o caso de teste responde: <br>**"Como vou verificar esse comportamento?"**

## O papel do QA
O QA identifica os cenários de teste a partir dos requisitos, User Stories e critérios de aceite, buscando garantir que todas as funcionalidades e fluxos relevantes sejam contemplados antes da elaboração dos casos de teste.
