# 📖 2.13. Test Data
**Dados de Teste** são os dados utilizados durante a execução dos testes para verificar o comportamento do software em diferentes situações.

Esses dados podem representar situações válidas, inválidas, limites e diferentes combinações de entradas.

Os dados de teste permitem verificar se o sistema se comporta corretamente diante das diferentes condições previstas nos requisitos.

A escolha adequada dos dados contribui para uma cobertura mais completa dos cenários de teste.

## Exemplos
Para um campo que aceita valores entre **18 e 60 anos**, alguns dados de teste podem ser:
- **18** → valor mínimo válido.
- **60** → valor máximo válido.
- **17** → valor abaixo do limite.
- **61** → valor acima do limite.
- **25** → valor dentro da faixa válida.
- **Campo vazio** → entrada inválida.

Os dados utilizados devem estar de acordo com o objetivo do teste.

## Tipos de dados de teste
Dependendo do objetivo do teste, podem ser utilizados diferentes tipos de dados, como:
- **Dados válidos** — devem ser aceitos pelo sistema.
- **Dados inválidos** — devem ser rejeitados ou tratados adequadamente.
- **Dados de limite** — utilizados para verificar valores próximos ou nos limites definidos.
- **Dados ausentes** — utilizados para verificar o comportamento diante de campos não preenchidos.

## O papel do QA
O QA identifica e prepara os dados necessários para executar os testes, considerando os requisitos, os cenários de teste e as condições que precisam ser validadas.

Os dados devem ser adequados ao objetivo do teste e permitir a reprodução dos cenários quando necessário.

## 💡 Boa prática
Os dados de teste devem ser planejados de acordo com os cenários que serão executados. Também é importante evitar o uso de dados reais ou sensíveis quando não forem necessários para os testes.
