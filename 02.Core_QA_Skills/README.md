# 📚 2. Core QA Skills
Este módulo reúne as principais competências utilizadas por um profissional de QA no dia a dia. São apresentados conceitos, técnicas e artefatos relacionados à análise de requisitos, planejamento, elaboração e documentação de testes, além das práticas utilizadas para identificar, registrar e acompanhar defeitos durante o desenvolvimento de software.

## 🎯 Learning Outcomes
Ao concluir este módulo, serei capaz de:

- Compreender os principais conceitos relacionados aos requisitos de software.
- Interpretar User Stories e Acceptance Criteria.
- Analisar requisitos e identificar riscos.
- Elaborar planos e estratégias de teste.
- Aplicar técnicas de projeto de testes.
- Criar cenários, casos de teste e checklists.
- Selecionar dados de teste adequados aos cenários.
- Elaborar relatórios de defeitos claros e objetivos.
- Compreender o ciclo de vida de um defeito.
- Relacionar requisitos aos testes utilizando uma RTM.
