# 2.12. Requirement Traceability Matrix (RTM)
A **Matriz de Rastreabilidade de Requisitos (RTM)** é um documento utilizado para relacionar os requisitos do software aos respectivos casos de teste.

Ela permite acompanhar quais requisitos foram cobertos pelos testes e identificar possíveis lacunas na cobertura.

O principal objetivo da RTM é garantir a **rastreabilidade entre requisitos e testes**, ajudando a verificar se todos os requisitos relevantes foram considerados durante o processo de teste.

Ela também facilita a identificação de requisitos que não possuem casos de teste associados.


## Como funciona
A RTM estabelece uma relação entre os requisitos e os testes correspondentes.

### Por exemplo:

| Requirement ID | Requisito                                      | Test Case ID | Status       |
| -------------- | ---------------------------------------------- | ------------ | ------------ |
| REQ-001        | O usuário deve conseguir realizar login.       | TC-001       | Passed       |
| REQ-002        | O sistema deve bloquear credenciais inválidas. | TC-002       | Failed       |
| REQ-003        | O usuário deve conseguir recuperar a senha.    | TC-003       | Not Executed |

Dessa forma, é possível acompanhar quais requisitos possuem cobertura de testes e qual foi o resultado da execução.

## Benefícios
A utilização da RTM ajuda a:
- Garantir a cobertura dos requisitos.
- Identificar requisitos sem testes associados.
- Facilitar o acompanhamento da execução dos testes.
- Identificar impactos quando um requisito é alterado.
- Fornecer evidências da cobertura de testes.

## O papel do QA
O QA utiliza a RTM para acompanhar a relação entre os requisitos e os testes, verificando se os requisitos relevantes possuem cobertura adequada e mantendo a rastreabilidade durante o ciclo de testes.

## 💡 Boa prática
A RTM deve ser atualizada quando houver alterações nos requisitos ou nos testes relacionados. Isso mantém a rastreabilidade consistente e facilita a identificação de impactos causados por mudanças no sistema.
