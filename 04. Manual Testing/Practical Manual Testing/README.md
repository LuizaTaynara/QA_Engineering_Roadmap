# 🛍️SauceDemo - Manual Testing

## 🎯Objetivo do projeto
Demonstrar competências em Quality Assurance através do planeamento, documentação e execução de testes manuais na aplicação Sauce Demo.
Este repositório reúne artefactos de teste elaborados durante os meus estudos em QA, incluindo plano de testes, casos de teste, checklists, evidências e relatórios de defeitos.

## 🌐Aplicação testada
 - [Plataforma Sauce Demo](https://www.saucedemo.com/)

## 💻Ambiente de teste
- Sistema Operativo: Windows 11 Pro
- Navegador: Google Chrome 149.0.7827.103 (64 bits)
- Dispositivo: Desktop

## ❌​Fora do escopo
- Testes de desempenho
- Testes de segurança
- Testes em múltiplos navegadores e dispositivos
- Testes de integrações externas
- Testes de aceitação

## 🛠️Ferramentas utilizadas
- Google Chrome: execução dos testes manuais na aplicação web.
- Google Sheets: criação e gestão dos casos de teste e checklists.
- Jira: registo e acompanhamento dos defeitos identificados.

## 📌Competências demonstradas
- Planeamento de testes
- Escrita de casos de teste
- Execução de testes manuais
- Reporte de defeitos
- Validação de requisitos
- Testes funcionais
- Testes de sistema
- Organização da documentação de QA
