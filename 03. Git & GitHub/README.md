# 📚 3. Git & GitHub
Este módulo apresenta os principais conceitos e recursos utilizados para trabalhar com controle de versão e colaboração por meio do Git e GitHub. O conteúdo aborda repositórios locais e remotos, branches, merge, Pull Requests, Issues e GitHub Actions, além de apresentar um fluxo básico de trabalho aplicado ao contexto de QA.


## 🎯 Learning Outcomes
Ao concluir este módulo, serei capaz de:

- Compreender os fundamentos do Git e do controle de versão.
- Trabalhar com repositórios locais e remotos.
- Criar e utilizar branches para separar alterações.
- Integrar alterações utilizando merge.
- Criar e revisar Pull Requests.
- Utilizar Issues para registrar e acompanhar tarefas e problemas.
- Compreender os conceitos básicos do GitHub Actions.
- Utilizar GitHub Actions para automatizar tarefas relacionadas aos testes.
- Compreender um fluxo básico de trabalho com Git e GitHub aplicado ao contexto de QA.
