# 3.04 Test Cases — Checkout
| ID               | Test Case                              | Pré-condições                                               | Passos                                                | Resultado esperado                                                                                   |
| ---------------- | -------------------------------------- | ----------------------------------------------------------- | ----------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| **TC-CHECK-001** | Exibição da primeira etapa do checkout | Utilizador autenticado e pelo menos um produto no carrinho. | 1. Aceder ao carrinho.<br>2. Clicar em **Checkout**. | A primeira etapa do checkout é apresentada e os campos necessários para continuar estão disponíveis. |
| **TC-CHECK-002** | Campo "First Name" vazio no checkout step one   | Utilizador na primeira etapa do checkout. | 1. Deixar First Name vazio.<br>2. Inserir `Doe` no campo Last Name.<br>3. Inserir `1000-100` no campo Postal Code.<br>4. Clicar em **Continue**. | O sistema impede o avanço e apresenta uma mensagem indicando que o nome é obrigatório.   |
| **TC-CHECK-003** | Campo "First Name" somente com números no checkout step one   | Utilizador na primeira etapa do checkout. | 1. Inserir `12345` no campo First Name.<br>2. Inserir `Doe` no campo Last Name.<br>3. Inserir `1000-100` no campo Postal Code.<br>4. Clicar em **Continue**. | O sistema deve rejeitar o valor informado e impedir o avanço para a próxima etapa do checkout.    |
| **TC-CHECK-004** | Campo "Last Name" vazio no checkout step one   | Utilizador na primeira etapa do checkout. | 1. Inserir `John` no campo First Name.<br>2. Deixar Last Name vazio.<br>3. Inserir `1000-100` no campo Postal Code.<br>4. Clicar em **Continue**. | O sistema impede o avanço e apresenta uma mensagem indicando que o Sobrenome é obrigatório.       |
| **TC-CHECK-005** | Campo "Last Name" somente com números no checkout step one  | Utilizador na primeira etapa do checkout. | 1. Inserir `John` no campo First Name.<br>2. Inserir `12345` no campo Last Name.<br>3. Inserir `1000-100` no campo Postal Code.<br>4. Clicar em **Continue**. | O sistema deve rejeitar o valor informado e impedir o avanço para a próxima etapa do checkout. |
| **TC-CHECK-006** | Campo "Zip/Postal Code" vazio no checkout step one  | Utilizador na primeira etapa do checkout. | 1. Inserir `John` no campo First Name.<br>2. Inserir `Doe` no campo Last Name. <br>3. Deixar Postal Code vazio.<br>4. Clicar em **Continue**. | O sistema impede o avanço e apresenta uma mensagem indicando que o código postal é obrigatório. |
| **TC-CHECK-007** | Campo "Zip/Postal Code" somente com letras no checkout step one | Utilizador na primeira etapa do checkout. | 1. Inserir `John` no campo First Name.<br>2. Clicar em **Continue**. | O sistema deve rejeitar valores inválidos no campo Postal Code e impedir o avanço no checkout. |
| **TC-CHECK-008** | Todos os campos obrigatórios vazios no checkout step one | Utilizador na primeira etapa do checkout. | 1. Deixar todos os campos vazios.<br>2. Clicar em **Continue**.  | O sistema impede o avanço e apresenta uma mensagem de validação para todos os campos obrigatórios. |
| **TC-CHECK-009** | Preenchimento válido de todas as informações no checkout step one | Utilizador na primeira etapa do checkout. | 1. Inserir `John` no campo First Name.<br>2. Inserir `Doe` no campo Last Name. <br>3. Inserir `1000-100` no campo Postal Code.<br>4. Clicar em **Continue**. | As informações são aceitas e o utilizador avança para a etapa seguinte do checkout. |
| **TC-CHECK-010** | Cancelar checkout no step one  | Utilizador na primeira etapa do checkout.  | 1. Clicar em **Cancel**. | O checkout é cancelado e o utilizador retorna ao carrinho.          |
| **TC-CHECK-011** | Visualização dos produtos no checkout step two | Utilizador avançou para a etapa de resumo com pelo menos um produto no carrinho. | 1. Verificar os produtos apresentados no resumo.<br>2. Comparar com os produtos adicionados ao carrinho. | Os produtos apresentados no resumo correspondem aos produtos adicionados ao carrinho.                      |
| **TC-CHECK-012** | Validação dos valores no checkout step two    | Utilizador na etapa de resumo do checkout.      | 1. Verificar os preços dos produtos.<br>2. Verificar os valores apresentados no resumo.      | Os valores apresentados correspondem aos produtos selecionados e aos cálculos apresentados pela aplicação. |
| **TC-CHECK-013** | Retornar ao step one a partir do step two | Utilizador na etapa de resumo do checkout. | 1. Clicar em **voltar(ou back)**. | O utilizador volta para o step one e as informações preenchidas foram salvas. |
| **TC-CHECK-014** | Cancelar checkout na etapa checkout step two | Utilizador na etapa de resumo do checkout. | 1. Clicar em **Cancel**. | O checkout é cancelado e o utilizador retorna para a página do carrinho. |
| **TC-CHECK-015** | Conclusão de uma compra    | Utilizador na etapa de resumo com pelo menos um produto no carrinho. | 1. Verificar os dados do pedido.<br>2. Clicar em **Finish**.      | A compra é concluída e a página de **checkout complete** é apresentada.   |
| **TC-CHECK-016** | Validação da mensagem de confirmação | Compra finalizada.          | 1. Verificar a página de confirmação.<br>2. Verificar a mensagem apresentada. | A mensagem de confirmação da compra é apresentada corretamente. |
| **TC-CHECK-017** | Validação do botão "Back Home" no checkout complete | Compra finalizada.   | 1. Clicar no botão **Back Home**. | O utilizador é redirecionado para a página de produtos. |
| **TC-CHECK-018** | Validação do botão "Generate PDF order" no checkout complete | Compra finalizada.   | 1. Clicar no botão **Generate PDF order** | O utilizador é redirecionado corretamente a geração/download do documento. |
| **TC-CHECK-019** | Carrinho vazio após a conclusão da compra | Compra finalizada.    | 1. Verificar se o carrinho ficou vazio após a compra ser concluída. | O utilizador é redirecionado para a página de produtos e o carrinho está vazio. |
