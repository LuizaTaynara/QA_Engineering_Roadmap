# 3.01 Test Cases — Login
| ID               | Test Case                     | Pré-condições                                     | Passos                                                                                                                                                    | Resultado esperado                                                    |
| ---------------- | ----------------------------- | ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| **TC-LOGIN-001** | Login com credenciais válidas | Aplicação acessível e utilizador não autenticado. | 1. Aceder à página de login.<br>2. Inserir `standard_user` no campo Username.<br>3. Inserir `secret_sauce` no campo Password.<br>4. Clicar em **Login**. | O utilizador é autenticado e é direcionado para a página de produtos. |
| **TC-LOGIN-002** | Login com username inválido | Aplicação acessível e utilizador não autenticado. | 1. Aceder à página de login.<br>2. Inserir um username inválido.<br>3. Inserir `secret_sauce` no campo Password.<br>4. Clicar em **Login**.   | O login não é realizado e uma mensagem de erro apropriada é apresentada. |
| **TC-LOGIN-003** | Login com password inválida | Aplicação acessível e utilizador não autenticado. | 1. Aceder à página de login.<br>2. Inserir `standard_user` no campo Username.<br>3. Inserir uma password inválida.<br>4. Clicar em **Login**. | O login não é realizado e uma mensagem de erro apropriada é apresentada. |
| **TC-LOGIN-004** | Login com credenciais inválidas | Aplicação acessível e utilizador não autenticado. | 1. Aceder à página de login.<br>2. Inserir Username e password inválida.<br>3.Clicar em **Login**.  | O login não é realizado e uma mensagem de erro apropriada é apresentada.|
| **TC-LOGIN-005** | Login com username vazio             | Aplicação acessível e utilizador não autenticado. | 1. Aceder à página de login.<br>2. Deixar o campo Username vazio.<br>3. Inserir `secret_sauce` no campo Password.<br>4. Clicar em **Login**.  | O login não é realizado e o sistema apresenta uma mensagem indicando que o username é obrigatório.   |
| **TC-LOGIN-006** | Login com password vazia             | Aplicação acessível e utilizador não autenticado. | 1. Aceder à página de login.<br>2. Inserir `standard_user` no campo Username.<br>3. Deixar o campo Password vazio.<br>4. Clicar em **Login**. | O login não é realizado e o sistema apresenta uma mensagem indicando que a password é obrigatória.   |
| **TC-LOGIN-007** | Login com username e password vazios | Aplicação acessível e utilizador não autenticado. | 1. Aceder à página de login.<br>2. Deixar Username e Password vazios.<br>3. Clicar em **Login**.  | O login não é realizado e o sistema apresenta uma mensagem de validação para os campos obrigatórios. |
| **TC-LOGIN-008** | Login com utilizador bloqueado | Aplicação acessível e utilizador não autenticado. | 1. Aceder à página de login.<br>2. Inserir `locked_out_user` no campo Username.<br>3. Inserir `secret_sauce` no campo Password.<br>4. Clicar em **Login**. | O acesso é recusado e uma mensagem indicando que o utilizador está bloqueado é apresentada. |
| **TC-LOGIN-009** | Ocultação da palavra-passe | Aplicação acessível e utilizador não autenticado. | 1. Aceder à página de login.<br>2. Inserir uma palavra-passe no campo Password. | Os caracteres inseridos no campo Password são ocultados. |
| **TC-LOGIN-010** | Logout de utilizador autenticado | Utilizador autenticado na aplicação. | 1. Abrir o menu da aplicação.<br>2. Clicar em **Logout**. | A sessão é encerrada e o utilizador retorna à página de login. |
